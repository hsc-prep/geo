# Year 12 Geography Revision Suite

HTML revision tools for Year 12 HSC Geography (NSW syllabus, first HSC 2025), built to be hosted as a static site (e.g. GitHub Pages). Each `.html` file is a page; each page loads its own companion `.js` data file(s) alongside the shared styling/engine that's inlined in every page.

## Pages

| File | Contents |
|---|---|
| `Geo12_Revision_Hub.html` | Start here — quick-nav to every page/bank, "how to revise" guidance, tile menu |
| `Geo12_SyllabusChecklist.html` | All 37 syllabus dot points across the three topics, with Reviewed/Practised checkboxes |
| `Geo12_DirectiveTerms.html` | 18 directive terms glossary, flashcards, essay-writing strategy (CUBE, DAWSS), self-marking quiz |
| `Geo12_Topic1_Sustainability.html` | Topic 1 notes, flashcards, named case-study boxes, questions to practise, real exemplar answers |
| `Geo12_Topic2_Ecosystems.html` | Topic 2 notes, flashcards, questions to practise, real exemplar answers |
| `Geo12_Topic3_RuralUrban.html` | Topic 3 notes, flashcards, questions to practise, real exemplar answers |
| `Geo12_Q16_Skills.html` | Multiple-choice skills bank, Written Skills (Q16) bank, and construction guides (climate graphs, population pyramids, ternary graphs, cross sections, transects, précis maps) |
| `Geo12_Q17_GeographicalInvestigation.html` | Evaluating fieldwork, vocations, Environmental Impact Studies |
| `Geo12_ExamBuilder.html` | Generates a full practice exam in the real HSC structure — Section I (15 MC), Section II (Q16, Q17, one question per unit, an integrated question), Section III (Question 22, tiered), Section IV (Question 23, essay) — with ruled writing lines, and prints it to PDF |
| `index.html` | Redirects the bare site URL to `Geo12_Revision_Hub.html`, so `https://<username>.github.io/<repo>/` works without students needing the full Hub filename |

## Data files

Large content arrays (question banks, flashcards, syllabus notes, case-study banks) live in their own companion `.js` files rather than inline in each page, so they load as ordinary HTTP requests rather than bloating every page's HTML:

| File | Used by |
|---|---|
| `sustainability_data.js` | Unit 1 notes/flashcards, Topic 1 written practice, Topic 1 case studies — used by the Topic 1 page and the Syllabus Checklist |
| `ecosystems_data.js` | Unit 2 notes/flashcards, Topic 2 written practice — used by the Topic 2 page and the Syllabus Checklist |
| `rural_urban_data.js` | Unit 3 notes/flashcards, Topic 3 written practice — used by the Topic 3 page and the Syllabus Checklist |
| `directive_terms_data.js` | The 18-term glossary + self-marking quiz bank — used by the Directive Terms page |
| `q16_skills_data.js` | The MC skills bank + Written Skills (Q16) bank — used by the Q16 page and the Exam Builder |
| `exam_data.js` | Section II/IV question pools sized specifically for the Exam Builder |

Each page's `<script src="...">` tag for its data comes before the shared engine script that reads it. Small lookup/config objects (e.g. the self-authored Q17 and exam-integration banks) stay inline in the page itself.

## How it works

- Student progress (flashcard position, quiz answers, written-practice mastery, saved name, checklist ticks) is stored in the browser's `localStorage`, per file, per device. It is never sent anywhere.
- Every page can print to PDF via the browser's print dialog (Ctrl/Cmd+P), including a dedicated "Print flashcards" and "Print my answers" button where relevant.

## Updating content

The site is generated by `assemble.py` from source JSON/data files (not included in this distribution repo) — this repo holds the built, ready-to-host output. For small wording tweaks, editing the relevant `.html` or `.js` file directly also works; there's no build step required to host what's here.

## Publishing with GitHub Pages

1. Push this repository to GitHub.
2. In the repo's Settings → Pages, set the source to the `main` branch, root folder.
3. Share the resulting `https://<username>.github.io/<repo>/` link with students — `index.html` redirects it straight to the Hub.
